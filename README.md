# Fit Board

Live site: https://albierrto.github.io/fit-board/

A phone-friendly outfit board:

- **Wear**: outfits you can put on today with clothes you already own, plus a "pick an outfit for me" button
- **Buy next**: the few pieces that unlock the most new outfits, cheapest version first
- **Ideas**: Old Navy deals, zany designer finds, and classics to work toward
- **My closet**: what you own; tap anything else you own and the outfits update (saved on that device)

On a phone, open the link and use "Add to Home Screen" to keep it like an app.
